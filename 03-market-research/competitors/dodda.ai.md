## Product Portfolio

dodda.ai operates **two interconnected product lines:**

### **1. Site Feasibility Assistant (Land Intelligence Platform)**

**What it does:**  
Automates comprehensive site investigation and feasibility analysis for real estate development by aggregating data from 150+ sources into actionable Site Investigation Reports (SIR).

**Key Features:**

**Data Aggregation & Intelligence**

- 150+ authentic government, environmental, utility, and regulatory sources
- Single command center eliminating fragmented research
- Real-time policy change tracking
- Multi-layer intelligence synthesis (zoning + environmental + utilities + regulatory)

**Comprehensive SIR Generation** Reports include:

- Complete zoning analysis (codes, constraints, setbacks, height limits, lot coverage)
- Primary & accessory dwelling unit requirements
- Topographical data (elevation, soil types)
- Environmental & climate risk assessment (FEMA flood zones, disaster declarations)
- Utilities infrastructure mapping (electricity, gas, telecommunications providers with rates & coverage)
- Authorities Having Jurisdiction (AHJ) contacts at city/county/state levels
- Complete regulatory code references (building codes, municipal ordinances)
- Risk flagging (climate, environmental, infrastructure distance calculations)

**Workflow Integration**

- Financial workflow integration
- Project dashboard for multi-site tracking
- Team collaboration tools (Professional/Enterprise tiers)
- API access for custom integrations (Enterprise)

**Speed Metrics:**

- Traditional process: 100+ hours
- dodda.ai process: <10 minutes
- **Time savings: 20x+**

### **2. Permit Processing & Code Compliance Platform**

**What it does:**  
AI-driven permit processing that flags code violations in building drawings, reducing permit iterations and costly rework.

**Key Features:**

- Automated code violation detection in drawings
- Faster permit approvals (fewer RFI cycles)
- Integration with design tools (AutoCAD, Revit, etc.)
- Centralized access to building codes and documents
- Improved project predictability
