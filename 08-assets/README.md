# Assets - Parcel AI

## Overview

Эта папка содержит все вспомогательные материалы для Product Knowledge Base.

---

## Structure

### presentations/
Презентации для клиентов, инвесторов, партнеров

**Naming convention**: `YYYY-MM-DD_purpose_audience.pdf`

**Examples**:
- `2025-01-15_product-demo_enterprise-clients.pdf`
- `2025-01-20_investor-pitch_series-a.pdf`

### spreadsheets/
Таблицы, расчеты, финансовые модели

**Naming convention**: `YYYY-MM-DD_description.xlsx`

**Examples**:
- `2025-01-15_market-sizing-calculations.xlsx`
- `2025-01-20_pricing-analysis.xlsx`

### mockups/
Дизайн-макеты, wireframes, прототипы

**Naming convention**: `YYYY-MM-DD_feature-name_version.fig`

**Examples**:
- `2025-01-15_dashboard-redesign_v2.fig`
- `2025-01-20_mobile-app_wireframes.fig`

### documents/
Различные документы (контракты, case studies, белые книги)

**Naming convention**: `YYYY-MM-DD_document-type_description.pdf`

**Examples**:
- `2025-01-15_case-study_pnk-group.pdf`
- `2025-01-20_whitepaper_ai-logistics.pdf`

---

## Guidelines

### File Size
- Keep individual files under 10MB when possible
- For larger files, use cloud storage and link here
- Compress images before uploading

### Confidentiality
- Mark confidential files clearly in filename: `CONFIDENTIAL_`
- Do not commit sensitive client data
- Use .gitignore for sensitive files

### Versioning
- Include version numbers in filename if multiple versions exist
- Archive old versions in `archive/` subfolder

### File Formats

**Presentations**:
- Preferred: PDF (for sharing), PPTX (for editing)
- Tools: Google Slides, PowerPoint, Keynote

**Spreadsheets**:
- Preferred: XLSX, Google Sheets
- Include formulas and source data

**Mockups**:
- Preferred: Figma, Sketch, Adobe XD
- Export static versions as PNG/PDF for reference

**Documents**:
- Preferred: PDF (for finalized), DOCX (for drafts)
