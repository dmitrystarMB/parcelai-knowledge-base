# Parcel AI - Product Knowledge Base

Центральный репозиторий для всей продуктовой документации Parcel AI.

## О проекте

Parcel AI - платформа автоматизации логистических операций с использованием искусственного интеллекта.

## Структура репозитория

### 📋 01-product-vision/
Видение продукта, позиционирование и бизнес-модель
- `vision.md` - общее видение и миссия продукта
- `positioning.md` - позиционирование на рынке
- `target-segments.md` - целевые сегменты клиентов
- `business-model.md` - бизнес-модель и монетизация

### 👥 02-clients/
Информация о клиентах и их фидбек
- `README.md` - обзор клиентской базы
- `pnk-group/` - документация по клиенту PNK Group
- `potential-clients/` - потенциальные клиенты
- `feedback-summary.md` - сводка обратной связи

### 📊 03-market-research/
Исследование рынка и конкурентный анализ
- `competitors/` - анализ конкурентов
- `market-size.md` - размер рынка и возможности
- `trends.md` - тренды и прогнозы

### ⚙️ 04-product-features/
Функциональность продукта
- `current-features.md` - текущие функции
- `feature-requests.md` - запросы на новые функции
- `feature-prioritization.md` - приоритизация функций
- `features/` - детальные описания отдельных функций

### 🗓️ 05-product-roadmap/
Дорожная карта развития продукта
- `roadmap-2025.md` - план на 2025 год
- `q1-2025.md` - план на Q1 2025
- `mvp-status.md` - статус MVP

### 📝 06-requirements/
Требования к продукту
- `functional-requirements.md` - функциональные требования
- `non-functional-requirements.md` - нефункциональные требования
- `technical-constraints.md` - технические ограничения

### 🎤 07-customer-development/
Customer Development и исследования
- `interview-template.md` - шаблон интервью
- `interviews/` - записи интервью
- `insights.md` - инсайты и выводы

### 📎 08-assets/
Вспомогательные материалы
- `presentations/` - презентации
- `spreadsheets/` - таблицы и расчеты
- `mockups/` - макеты и дизайны
- `documents/` - прочие документы

### 📅 09-meeting-notes/
Заметки с встреч
- Организованы по месяцам (YYYY-MM)

### 📜 10-changelog/
История изменений продукта
- `product-changelog.md` - журнал изменений

## Как работать с репозиторием

1. **Создание нового контента**: используйте соответствующие шаблоны из каждой секции
2. **Обновление документов**: регулярно актуализируйте информацию
3. **Конфиденциальность**: не коммитьте чувствительные данные клиентов
4. **Структура**: следуйте установленной структуре папок
