# Parcel AI - Product Knowledge Base

## Overview

This repository serves as the central Product Knowledge Base for **Parcel AI**, the land acquisition intelligence platform positioned as the "Bloomberg Terminal for Land." This knowledge base contains all essential product documentation, client information, market research, and strategic planning materials.

## Product Summary

- **Product Name:** Parcel AI
- **Positioning:** Bloomberg Terminal for Land
- **Description:** Land acquisition intelligence platform that provides comprehensive data and insights for land acquisition decisions
- **Current Stage:** MVP → Productization
- **Anchor Client:** PNK Group (currently using MVP)
- **Goal:** Market expansion and feature development

## Best Practices

1. **Keep Documentation Updated:** Regularly update documents as new information becomes available
2. **Use Templates:** Utilize provided templates for consistency
3. **Link Related Documents:** Create connections between related information
4. **Version Control:** Commit meaningful changes with descriptive messages
5. **Sensitive Information:** Never commit sensitive client data, credentials, or proprietary information
