## Структура документации по клиентам

Для каждого крупного клиента создается отдельная папка с следующими файлами:

- `overview.md` - общая информация о клиенте
- `feedback.md` - обратная связь от клиента
- `requirements.md` - требования клиента
- `meetings-log.md` - лог встреч
- `deliverables.md` - что поставляем/поставили
