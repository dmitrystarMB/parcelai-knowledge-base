## Процесс поставки

### Стандартный процесс

1. **Планирование**
   - Определение scope
   - Оценка ресурсов
   - Согласование timeline

2. **Разработка**
   - Реализация
   - Code review
   - Internal testing

3. **Testing**
   - QA testing
   - UAT с клиентом
   - Фиксация багов

4. **Delivery**
   - Развертывание
   - Документация
   - Обучение (если требуется)

5. **Acceptance**
   - Формальная приемка
   - Сбор feedback
   - Post-mortem
