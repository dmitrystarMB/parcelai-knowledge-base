## Feature Details

### 1. Data Center Intelligence Index

**What was shown:**
- Map with red outlines (owned parcels) + points (new transactions)
- LLC unmasking: click entity → see all properties
- Status taxonomy: Active, Under Construction, Planned, Land Banked
- Stealth buys (no announcements) vs. Verified buys (confirmed after close)

1. Select geographic area

## Use Cases

### Use Case 1: Find Data Center Sites with Power

**Goal:** Identify 100-200 acre parcels near high-voltage substations in Georgia

**Steps demonstrated:**
1. Visualize all 94,000 substations across US
2. Apply 230V+ voltage filter (reduces to ~10,000)
3. Select Georgia market
4. Draw custom shape around power infrastructure cluster
5. Add acreage filter (100-200 acres)
6. Result: 110 properties matching all criteria

**Time:** < 2 minutes
**Impressive:** Yes - massive time savings vs. manual research

**Can we do this:** Partial (have filtering, not infrastructure data)
**Our approach:** Would need to build power infrastructure database first
**Gap:** P0 🔴 - Power infrastructure data is table stakes

## PNK Insights

**Top PNK priorities** (from questions):
1. **Power infrastructure** - Asked multiple times, called "definitely invaluable"
2. **Fiber connectivity** - "Definitely invaluable", critical for AI workloads
3. **LLC unmasking** - Strong interest in enterprise add-ons
4. **Zoning intelligence** - Current major pain point
5. **Pre-due diligence scale** - Need to screen "hundreds of parcels"

**PNK pain points revealed:**
- Information scarcity: "Information is like gold here"
- Manual research burden: Currently using open-source data and brokers
- Zoning complexity: Must manually review "every county, township, ordinance map"
- Non-disclosure states: Pennsylvania (primary market) has very limited data
- Scale challenge: Need to pre-screen hundreds of parcels efficiently

**Unmet PNK needs:**
- Real-time alerts (Acres doesn't offer)
- Industrial transaction tracking (Acres doesn't have)
- Automated zoning monitoring (Acres admitted difficulty)
- Multi-vertical intelligence (Acres limited to DC + homebuilders)
- Better Pennsylvania data (Acres has severe limitation)

## Key Takeaways

**Product maturity:** Very mature - $15-30M ARR, 500K users, polished demo

**Competitive threat:** 🔴 Critical
- Strong product with years of data curation
- Multiple critical features we lack
- Established market leader position

**Our position:** Behind in infrastructure intelligence, competitive in workflow

**Summary:**
Acres.com demonstrated a mature, comprehensive land intelligence platform with several critical features Parcel AI lacks: LLC unmasking, power/fiber infrastructure data, data center sales comps, and hyperscaler tracking. PNK showed very high buying intent, particularly interested in power infrastructure ("definitely invaluable"), fiber mapping ("definitely invaluable"), and LLC unmasking. Key gaps identified: Acres struggles with real-time updates (30-day cadence), industrial tracking, and Pennsylvania non-disclosure data - all opportunities for Parcel AI.

**Most critical gaps:**
1. Power infrastructure intelligence (94K+ substations, voltage filtering) - P0 🔴
2. LLC unmasking / entity resolution - P0 🔴
3. Data center sales comparables database - P0 🔴
4. Fiber connectivity mapping - P0 🔴
5. Hyperscaler tracking index - P0 🔴

**Our advantages:**
1. Real-time data (vs. 30-day lag) ⭐
2. Workflow automation potential ⭐
3. Could do multi-vertical (vs. DC-only focus) ⭐
4. Could solve PA non-disclosure issue with ML ⭐
5. AI-powered zoning monitoring (vs. manual) ⭐
